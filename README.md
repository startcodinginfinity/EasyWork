# EasyWork

## AI-Powered HR & Workforce Management Platform

EasyWork is a full-stack HR and workforce management platform built with **Java, Spring Boot, PostgreSQL, and React**, with plans to integrate **Generative AI, RAG, and intelligent HR automation**.

### 🚀 Tech Stack

- Java
- Spring Boot
- Spring Security
- JWT Authentication
- PostgreSQL
- JPA / Hibernate
- REST APIs
- React.js
- AI / LLM / RAG

### 📦 Current Modules

- Company Management
- Department Management
- Employee Management
- User Management
- JWT Authentication

### 🤖 AI Roadmap

- AI HR Assistant
- Employee self-service AI
- HR policy question answering
- RAG-based knowledge search
- LLM integration
- Intelligent HR automation
- Vector database integration

### ▶️ Run Locally

1. Clone the repository.
2. Configure PostgreSQL.
3. Set the required environment variables.
4. Run the Spring Boot application.
5. Test the APIs using Postman.
